# Giant Reload

## ローカル起動

```powershell
npm install
npm start
```

ブラウザで `http://localhost:3000` を開きます。`server.js` がHTML配信とWebSocketの部屋管理を担当します。

## 部屋機能

- メニュー、部屋設定中、一時停止中に操作プリセットと設定を変更可能。移動、照準、射撃、リロード、武器切替、全画面、一時停止、ミュートなどのキーを各操作2つまで割り当て可能。設定中に `Esc` を押すとそのキーを解除
- 部屋コードで参加
- オーナーだけがゲーム開始可能
- オーナーがゲーム時間、勝利キル数、ボット人数（0〜16人）、弓の照準自動補正（初期設定はオン）を設定
- オーナーはチーム戦（2〜4チーム）とチーム分け（ランダム／手動）を設定可能。チーム戦はチーム合計キル数で勝敗を判定し、手動設定ではプレイヤーとボットをドラッグまたは選択欄でチーム間移動可能
- 部屋画面でプレイヤーとボットの所属チームを確認可能。試合中も同じチームのキャラクターとスコア表示はチームカラーで統一。ボット人数を調整してチーム人数を補完
- WebSocketで参加者一覧と開始設定を同期
- オンライン対戦中のプレイヤー状態と飛行中の矢を同期
- iframe内で開いた場合も、ページと同じホストへのWebSocket接続を使用

## 無料公開の想定

フロントエンドとWebSocketサーバーを同じNode.jsサービスとして公開できる構成です。RenderなどのNode.js Web Serviceにリポジトリを接続し、Build Commandを `npm install`、Start Commandを `npm start` にします。無料枠では停止・再起動により接続が切れる場合があるため、公開時には自動再接続を追加します。

## 注意

現在の通信層は部屋管理、オーナー権限、設定同期、開始通知、プレイヤー状態の中継までを実装しています。対戦を完全なホスト権威型にするには、次の段階で弾道・命中・キル・マッチ終了をサーバー側で検証する必要があります。
